# Atlas de la base

Mapa interactivo de una fábrica de Factorio (Space Age 2.1) con recorrido guiado, rutas de cada material y la explicación de cada objeto, pensado para quien nunca ha jugado.

- [Atlas de la base](https://xnowocodes.github.io/atlas-factorio/): el mapa interactivo (`index.html`).
- [Diseño de la ciencia automática](https://xnowocodes.github.io/atlas-factorio/diseno.html): propuesta para automatizar la investigación y el combustible, probada en una copia de la partida. Todavía no está aplicada en el juego (`diseno.html`).
